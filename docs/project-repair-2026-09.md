## 开发成本

- `pnpm dev` 首次启动构建 Electron 代码；监听 `src/main`、`src/preload`、`src/core`、`src/shared`，编译成功后才重启 Electron。renderer 继续使用 Vite。
- `pnpm test:unit` 构建 worker 所需的 Electron JavaScript 并运行不启动 Electron 窗口的测试；不构建 renderer。不能假定 worker 测试完全不需要构建。
- `pnpm test` 仍是完整检查；CI 不再紧接着重复执行 `pnpm build` 和包含 build 的协议脚本。
- 协议探针从已构建的迁移模块读取当前 schema 版本，不再固定断言 schema 2；开发入口等待本机服务时显式绕过代理。
- 删除三组仅用源码字符串证明学习交互存在的检查，补上真实组件交互；移除一组把 CSS 像素值锁死的检查。安全边界、数据迁移、幂等和跨平台互操作验证保留。
- 可读性整理以排版为主，没有引入新的格式化依赖、格式门禁或框架。
