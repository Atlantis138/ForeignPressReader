# Windows / Android 功能与数据对齐检查

日期：2026-10-03。范围：当前工作区源码（含原有未提交的桌面目录/自定义模型改动），不代表已发布 1.0.0 安装包。

## 检查结论与修复

目录译文丢失的原因是 Electron 服务只保存最多 8 个内存快照。关闭进程或挤出快照后必须重新请求模型。现改为两端本机文件缓存，完整与部分结果均能跨重启读取；按内容、模型、提示词版本区分，超过 64 MiB 时按修改时间淘汰旧缓存。界面隐藏译文不会删除缓存。缓存未进入便携备份或局域网同步。

近期桌面新增功能未同步到 Android。本轮接入 Android 的目录翻译、取消、失败续译、强制重译、显示/隐藏、自定义模型保存/删除；共用目录交互状态。修复 Android 缓存异步加载后的目录滚动恢复，保留折叠/显示状态，文章译文字号改为跟随正文。

原生实现另有差异：Android 收到重复 ID 会重复计数，模型漏项直接失败，临时网络错误不会像 Windows 一样重试。本轮由正文/目录共用批次执行器，增加去重、最多三轮漏项补译、临时错误重试、截断拆批以及请求前后的取消检查。网络请求放入阻塞工作线程。取消或清理会使旧任务失效，已完成条目继续保留；清理期间不能启动新的桌面目录翻译。

Android“测试所选模型”此前测试已保存选择，现在传递表单当前选择。自定义模型两端均按供应商区分，最多 100 项，删除当前自定义模型回退到内置选择；Windows 旧配置仍可读取。

## 逐域核对

| 领域 | 当前对齐情况 / 实现依据 |
| --- | --- |
| 书库 | 两端均有 EPUB 导入/取消、分类、重命名、排序、网格/列表、批量归类/删除、继续阅读；同源 EPUB 内容补全与资源恢复有双运行时测试。桌面侧栏与手机导航按平台布局。 |
| 阅读与搜索 | 两端复用 `ArticleSearch`、`ArticleReadingTools`，覆盖全库正文检索、每篇位置、书签/已读、保留译文版本；稳定锚点、正文搜索与上下项、查词、收藏语境均有实现。 |
| 目录 / 翻译 | 本轮补齐上述缺口。原文/译文并列、断点续译、模型缓存隔离、重译和取消语义一致；手机保留折叠栏目和触摸控件。 |
| 词典 / 生词 | 共用逻辑 DTO 与词条展示；ECDICT standard/full、英中检索、词集/权威/词频筛选、分页、生词快照、语境回原文、百度增强与 AI 文中义均覆盖。对应 `dictionary*`、`lexicon-core`、`mobile-parity-contract`、词典原生测试。 |
| 学习 | 两端使用相同 proposal v2 / FSRS 规则与向量；今日队列、额外批次、今日词表分页、计划/来源/逐词管理、强化/改判/太简单、普通删除保留进度与开发重置有回归。 |
| 外观 / UI 状态 | 主题、字号、行距、暖度与版心语义一致；手机窄屏自适应，桌面支持自定义宽度，移动端保留该值直到主动选择预设。本轮修复移动译文字号和目录异步恢复。错误/重试、进度/取消、危险操作确认、焦点管理保留两端模式。 |
| 语音 | 两端均有系统/Google/MiniMax、单词/文章独立配置、播放控制。Android 原生前台媒体服务负责锁屏/后台/通知，Windows 采用桌面播放运行时；属于平台适配。 |
| 用户数据 | 正式 migration 1–4、便携 v4、Sync Model v4、内容 ID v2 未改写。书库元数据、学习、阅读位置/标记/保留译文按既有规则合并；新缓存与本机模型清单不混入用户数据合同。 |
| 备份 / LAN | 两端共用逻辑数据集与兼容向量、导入预览、幂等合并、墓碑/重置和增量协议。跨 TypeScript/Rust 便携互操作单独验证。物理数据库、API Key、设备身份和缓存不互传。 |
| 设置 / 维护 | 翻译、词典、语音、学习、外观、存储、备份/同步、诊断/恢复均有入口。Windows 文件夹/DPAPI 与 Android SAF/系统存储/Keystore 使用平台原生实现。AI 文本清理现在包含目录译文，安全缓存清理保留它；保留的正式译文版本不受影响。 |

该核对以当前入口、客户端契约、存储路径和测试为依据；没有把平台导航、文件选择器、系统声音清单或后台音频实现要求成逐像素/逐代码一致。

## 验收边界

自动测试使用合成刊物、临时数据库和模拟模型响应，不调用用户付费 API、不修改用户数据库、不构建或覆盖安装正式应用。当前没有连接 Android 手机，本轮不能据此声称华为真机、真实锁屏/蓝牙、付费模型服务及真实双设备网络已通过新增功能验收。原有 Android 设备测试待办继续有效。
