## 3. 确定性视觉矩阵

运行 `pnpm ui:mobile:capture:e1`，共生成 84 张忽略 Git 的截图到 `test-artifacts/mobile-e1`。14 个场景包括：

- 书库普通网格、红框选择模式、紧凑列表；
- 刊物目录；
- 阅读器普通、当前文章搜索、缓存译文；
- 设置根页、阅读外观，以及翻译/词典/语音/学习/数据五个能力页。

每个场景覆盖 360 × 800、412 × 915 深色、915 × 412 横屏、600 × 960 且字体 1.3、840 × 1080 rail，以及 840 × 1080 深色且字体 1.5。捕获脚本同时执行布局断言：84 个页面均为零横向溢出；主按钮、图标按钮、设置行、目录文章行和一级导航均无关键触摸目标不足。

视觉审查结论：

- 360 dp 首屏可见书库管理工具与第一排刊物；设置首屏可见全部六个分区。
- 选择状态只有封面外侧红色双层框、阴影和轻微抬升；无圆形勾选框。
- 600 dp 为三列，840 dp 为四列并切换 80 dp navigation rail；窄横屏保持底部导航。
- 深色与 1.5 倍字体允许换行和页面增高，没有截断服务边界或缩小命中区。
- 阅读外观保留 Windows 的暖纸、墨色、编辑红、动态英文预览与红色左边框，但控件按手机单列组织。

截图、manifest 和 API 35 `screencap` 均位于忽略的 `test-artifacts`，不提交 PNG 二进制。

## 4. API 35 模拟器验收

设备：x86_64 Android API 35，物理分辨率 1080 × 2340，系统字体依次检查 1.0 与 1.5。

- 安装本轮 x86_64 debug APK，并使用既有模拟器本地书库验证 76 篇/20 栏目刊物；外部 EPUB 和用户数据库未进入仓库。
- 从既有文章冷启动恢复到阅读器，返回目录与书库后封面、文章/栏目数、分类、导入日期和继续阅读正常。
- 显式进入选择模式时即使 0 项也保持工具条；选择刊物后显示红色双层外框，不显示 checkbox。
- 切换到设置再返回书库，选择模式和选中项在当前进程内保留；Android Back 先退出选择，不跨 tab 跳转。
- 再次进入选择模式后强制结束并冷启动，临时选择模式和选中项被丢弃，安全书库状态恢复。
- 设置根页六个入口均可见；阅读外观页动态预览、主题切换和正式偏好即时生效，深色稳定帧正确。
- 横屏保持底部导航，页面可纵向滚动且无系统栏遮挡；系统字体 1.5 时标题、说明和预览自然换行，底部导航标签仍可辨识。
- 模拟器 `screencap` 在 WebView 硬件合成或主题切换紧邻帧偶尔出现黑块；等待稳定帧后恢复正常，确定性 Chromium fixture 未复现内容缺失。

导入取消、分类、排序、列表、重命名、批量归类/删除确认、目录、阅读器查找和阅读锚点同时由已有自动测试及本轮未改写的 E1 实现覆盖。本轮没有执行真实删除和低存储等破坏性模拟器操作。

## 5. 设置与 E4 边界

- 阅读外观完整可用，设置页和阅读器 sheet 复用相同正式偏好与控件。
- 翻译页只说明已有缓存译文可离线展示/搜索；Android 不调用模型网络，也不读取密钥。
- 词典页读取真实 ECDICT 安装状态，安装、删除和修复仍由词典模块承担。
- 语音页明确 D0 探针不是正式服务；系统/Google/MiniMax 留到 E4。
- 每日学习页只说明现有最小计划和 FSRS-6 闭环；完整计划在 E3、学习参数在 E4。
- 数据页说明 local-first、`formal-v1`、内容 ID v2 和旧 Demo 隔离；便携备份仍属于 F0，没有假按钮。
- `MobileReaderServiceSlots.translation` 与 `.speech` 继续为 `null`，没有增加公网、密钥或音频行为。

## 6. 架构与数据审计

- 保留 E1 已有 `LibraryApi`、`ReaderApi`、Rust commands、刊物生命周期删除和翻译缓存读取；本轮只增加 renderer 内部选择状态、设置路由/展示模型和目录折叠状态。
- `src/core` 未修改，仍为纯 TypeScript；renderer 仍只通过 `AppClient` 或受控移动扩展客户端访问能力。
- 未修改 `formal-v1` migration 1、便携备份 format v1、Sync Model v1 或内容 ID v2。
- 旧 `fpr.android.shell.v1` 的 `appearance-settings` 可映射到新阅读外观页，多余 `libraryQuery` 被安全忽略；快照版本未升级。
- 正式应用不读取、迁移或删除旧 Demo 数据。
- 待提交差异未发现 EPUB、用户数据库、ECDICT、密钥、备份、日志、截图、APK、NSIS 或其他构建产物。
