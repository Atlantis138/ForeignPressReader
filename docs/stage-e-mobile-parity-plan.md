# 阶段 E：Android 完整产品 UI 与 Windows 功能对齐计划

> 日期：2026-07-13
>
> 状态：E0 产品壳与 E1 书库/本地阅读已完成；E2 词典/我的生词、E3 背单词与 E4 设置/在线/系统服务已进入集成验证，完整设备、生命周期与性能门禁尚未关闭
>
> 对照基线：`src/renderer/App.tsx`、`reader/ReaderView.tsx`、`reader/DictionaryDrawer.tsx`、`dictionary/DictionaryPage.tsx`、`study/StudyPage.tsx`、`styles.css` 与完整 `AppClient`

## 1. 阶段定位

阶段 D 证明了 Android 可以在不改写 `formal-v1` migration 1、便携 format v1、Sync Model v1 和内容 ID v2 的前提下，完成“阅读点词 → 收藏生词/语境 → 建立最小计划 → 提交一张 FSRS 卡 → 冷启动恢复”的底层闭环。

阶段 E 的任务不再是继续堆叠薄页面，而是把 Android 变成与 Windows 同一产品：

- 四个一级功能统一为“我的书库、词典、背单词、设置”。
- 术语、信息层级、数据语义、状态反馈和主要操作尽量与 Windows 一致。
- 手机不直接缩小桌面双栏或侧栏；相同能力使用适合触摸、窄屏、系统返回键和安全区的交互表达。
- Windows 与 Android 共用 `AppClient` 逻辑能力和纯 TypeScript 领域规则，平台差异只留在外壳、原生端口和适配器。
- 每个 Windows 功能都必须在对照表中标为“同等覆盖、平台化调整、后置到 F/G、明确不支持”之一，不能无说明消失。

便携备份互通仍属于 F0，覆盖升级、低存储和 release 加固仍属于 F1，局域网同步仍属于 G。阶段 E 可以建立这些功能的设置入口和信息架构，但不得用占位成功结果伪装为已经实现。

## 2. Windows Electron 真实基线

### 2.1 应用壳与跨模块行为

Windows 当前不是四个互不相关的页面，而是一套带状态连续性的工作台：

- 左侧固定四项一级导航和本地状态标识。
- 四个一级区域分别保存路由、列表模式、筛选条件、选中项、非敏感草稿和滚动位置；切换后卸载隐藏 DOM，但回到模块时恢复用户上下文。
- 书库内部具有“书库 → 刊物目录 → 文章”层级；词典语境可以深链回原文章。
- 全局统一展示 busy 顶部进度、错误横幅、成功 toast、导入/安装/备份进度和取消操作。
- 离开文章、切换一级模块时停止当前朗读，避免后台声音和页面状态脱节。

Android E0 必须先复刻这些状态语义，再扩展页面；不能继续把词典、生词和复习作为书库首页上的临时按钮或 overlay 管理。

### 2.2 我的书库与阅读器

Windows 书库当前包含：

- EPUB 导入、进度、取消、重复导入反馈和空状态。
- 自定义分类的创建、重命名、删除；“全部书籍”和“未分类”固定入口。
- 按名称/导入时间排序、正序/倒序、图标/列表视图。
- 单本重命名、删除；选择模式、全选、批量归类和批量删除。
- 封面、书名、文章/栏目数、分类和导入时间信息。
- 刊物目录页、继续阅读、原刊栏目顺序、标题/导语和稳定返回。

Windows 阅读器当前包含：

- 标题、导语、栏目、日期、正文、图片、图注、列表和引用的统一排版。
- 稳定 block/token/比例锚点与像素回退，跨页面和布局变化恢复阅读位置。
- 当前文章搜索：英文搜索原文；含中文时额外搜索已有译文；上一项/下一项/关闭。
- 字号增减、主题切换、栏宽/行距/纸张暖度和设置深链。
- 全文批量翻译、取消、进度、失败重试；单段译文展开/收起。
- 点击查词、词形多候选、文中义分析、收藏生词、收藏语境和进入词典/生词。
- 单段朗读、从当前可见段落开始连续朗读、上一段/暂停继续/下一段/停止的播放控制。

### 2.3 词典与我的生词

Windows 词典当前包含：

- “词典检索 / 我的生词”两个模式及各自状态快照。
- 未安装引导、标准包/完整扩展安装、修复、降级、删除、进度和取消。
- 英中双向搜索、180 ms 防抖、结果总数和分页。
- 考研、高考等考试词集快捷入口。
- Oxford、Collins、BNC、当代词频、相关度/词频/字母序高级筛选。
- 结果列表与详情：音标、发音、考试/权威/词频徽标、词性释义、词形、例句。
- 我的生词搜索、取消收藏；无词典时继续展示收藏快照。
- 收藏语境列表和回到原刊文章；原刊已删除时保留不可跳转的快照。

### 2.4 背单词

Windows 背单词当前包含：

- 今日预览、到期复习/新词数、开始/继续、完成比例、用时、最近学习词和下一学习日。
- 今日完成后按计划“再学一批”。
- 今日词表及全部/新词/复习/首次认识/首次不认识/太简单筛选。
- 长期计划的创建、编辑、暂停、启用、归档；开发模式下可删除或连同相关进度重置。
- 计划来源可混合“我的生词”和多个考试词集；分别设置每日新词/复习配额。
- 来源同步状态和计划熟练度环形图。
- 计划词表搜索、分页，以及全部/到期/未学习/学习中/巩固中/熟练/暂停/排除筛选。
- 每词 D/S/R、due、复习次数、遗忘次数；逐词排除/恢复、暂停复习/恢复。
- 两阶段认识/不认识、认识后改判、答错后连续认识两次强化、太简单全局暂停、语境和学习例句。
- 单词发音与可选自动发音；命令幂等、版本冲突、事务回滚、跨日结转。

### 2.5 设置

Windows 设置当前包含七个分区：

1. 阅读外观：预览、字号、行距、栏宽、纸张暖度、浅色/深色、恢复默认。
2. 翻译服务：DeepSeek/OpenAI/Kimi 供应商、模型选择、独立密钥、保存、删除和连接测试。
3. 词典服务：点击查词/文中义开关、标准/完整 ECDICT 管理、本地/百度增强、回退本地、例句翻译、百度双密钥与连接测试。
4. 语音服务：单词/文章独立供应商、系统/Google/MiniMax、英语地区、系统声音、模型、音色、语速、自动学习发音、试听和独立密钥。
5. 每日学习：混合/复习优先/新词优先、学习日 cutoff、目标记忆率、最大间隔、保存/撤销。
6. 数据与存储：便携备份、导入预览和合并、进度/取消、分类存储报告、安全缓存/AI 文本缓存清理、同步占位和数据目录。
7. 开发与调试：隐藏入口、学习日推进、学习进度重置、脱敏日志、日志清理和恢复出厂。

## 4. 正式移动信息架构

### 4.1 一级导航

推荐方案作为 E0 默认实现：

- 手机竖屏：底部固定四项导航——“书库、词典、背单词、设置”。图标与文字同时显示，不增加第五个“我的生词”；“我的生词”属于词典内的并列模式，也是阅读器查词面板的深链目标。
- 手机横屏和常规手机：仍优先底部导航，避免窄横屏左侧占据正文宽度。
- 宽屏手机、折叠屏、平板：窗口宽度达到约 840 dp 后自适应为左侧窄 navigation rail；只复用同一四项结构，不复制 Windows 236 px 完整侧栏。
- 文章阅读、全屏答题、图片查看和破坏性确认时隐藏一级导航；返回上级后恢复。
- 目录、词条详情、计划详情、今日词表和设置子页使用顶部 app bar 与系统返回语义。

底部导航不是简单的 route 按钮。每个 tab 保存独立栈：

```text
书库：书库列表 → 刊物目录 → 文章
词典：词典检索/我的生词 → 词条详情 → 收藏语境 → 原文章
背单词：今日/计划列表 → 计划详情/今日词表 → 全屏答题
设置：设置分类 → 具体设置页/资源进度/危险确认
```

切换 tab 时保存栈顶页面、滚动位置、筛选、选中项和非敏感草稿；再次点击当前 tab 回到该 tab 根页并滚动到顶部，长按或二次点击不承载隐藏功能。

### 4.2 Android Back 规则

优先级固定为：

1. 关闭确认框、bottom sheet、词典抽屉或图片预览。
2. 退出搜索/选择模式等临时模式。
3. 返回当前 tab 的上一级页面，并恢复锚点。
4. 当前 tab 根页时交给系统返回；不偷偷切换到上一个 tab。

答题过程中返回必须先明确“退出但保留进度”，不得提交答案。安装、翻译、导入和备份等后台任务返回后继续，并在全局任务条中可见和可取消；不支持后台继续的任务必须明确提示。

### 4.3 桌面交互的移动表达

| Windows 表达 | Android 表达 |
| --- | --- |
| 固定左侧栏 | 手机底部导航；平板窄 navigation rail |
| 列表 + 详情双栏 | 手机列表进入全页详情；平板可恢复双栏 |
| hover 操作 | 显式更多菜单、滑动操作或进入选择模式；危险操作不只靠手势 |
| 右侧词典抽屉 | 可拖动 bottom sheet；横屏/平板可使用 side sheet |
| 桌面 modal | 简单操作用 bottom sheet；复杂表单/计划详情用全屏页面 |
| Ctrl+F、F3、Esc | 阅读器显式搜索按钮、上下项按钮、系统返回 |
| 原生 select | 单选 bottom sheet 或 Android 风格菜单 |
| 打开数据目录/日志目录 | 显示分类占用、导出/分享诊断文件；不暴露私有目录路径 |
| 鼠标批量选择 | 长按进入选择模式，同时提供显式“选择”入口 |

## 5. 视觉与组件原则

### 5.1 延续而非另起炉灶

Windows 的“现代报刊编辑部”语言保留为跨平台产品身份：

- 暖纸张背景、深墨正文、编辑红主色、低饱和成功/警告/危险色。
- UI 使用系统无衬线，刊名、页面标题和英文文章标题使用编辑感衬线。
- 红色只用于主操作、当前状态、重要进度和少量强调，不用于大面积装饰。
- 浅色/深色的语义令牌一致；正文阅读和工具界面共享纸张色，但层级阴影与边框可按平台调整。

当前 Android 首页超大标题和大按钮适合原型展示，不适合作为四模块正式壳。E0 应降低首页标题占屏比例，把首屏优先留给书籍、今日任务和搜索。

### 5.2 E0 必须冻结的令牌

- 颜色：canvas、paper、surface、surface-strong、ink、muted、line、accent、success、warning、danger、focus。
- 字体：UI、editorial、article 三套角色，而不是按页面临时声明。
- 间距：4/8/12/16/24/32/48 的统一阶梯。
- 圆角：小控件、卡片、sheet 三档；书籍封面保留书脊式非对称圆角。
- 阴影：普通卡片、浮层、模态三档；深色主题不用高亮灰边模拟阴影。
- 触摸：普通目标至少 48 dp，图标按钮至少 44–48 dp，按钮间距至少 8 dp。
- 动效：150–240 ms；遵守 reduced motion；加载不使用阻塞整页闪烁。
- 安全区：状态栏、导航条、刘海、键盘和横屏手势区统一由 shell 处理。

### 5.3 正式组件清单

E0 先建立移动端公共组件，不在各页面复制 CSS：

- `MobileAppShell`、`BottomNavigation`、`NavigationRail`、`TopAppBar`。
- `PageHeader`、`SectionHeader`、`EditorialCard`、`BookCover`、`StatusPill`。
- `PrimaryButton`、`SecondaryButton`、`DangerButton`、`IconButton`、`Toggle`、`SegmentedControl`、`ChoiceChip`。
- `SearchField`、`FilterSheet`、`SelectionBar`、`PaginationFooter`。
- `BottomSheet`、`SideSheet`、`FullScreenDialog`、`ConfirmDialog`。
- `InlineProgress`、`GlobalTaskBar`、`EmptyState`、`ErrorState`、`OfflineState`、`Skeleton`、`Snackbar`。
- `LexemeHeader`、`LexemeBadges`、`SenseList`、`ContextCard`、`StudyAnswerActions`。

## 6. 架构边界

### 6.1 不复制 Electron 页面

不要把 1,000 行 `App.tsx` 或桌面 CSS 响应式压缩后直接塞进 Android。应复用：

- `AppClient` 的逻辑能力和 DTO。
- `src/core` 的纯 TypeScript 领域规则。
- 词条释义、徽标、学习状态等可跨平台的无布局 presentation model。
- Windows 已验证的术语、状态机、确认语义和错误分类。

应平台化：

- 导航壳、布局、触摸手势、sheet/dialog、键盘与返回键。
- 文件选择器、Keystore、网络、系统 TTS、音频焦点、缓存目录和分享/导出。

### 6.2 客户端演进

- D0–D3 已冻结的 `MobileReadingClient` / `MobileLearningClient` 继续兼容，不原地改写其契约版本。
- 阶段 E 按模块增加窄扩展客户端，最终由 `AndroidAppClient` 组合成完整 `AppClient`；renderer 仍只调用逻辑方法。
- Rust repository 和 commands 不返回数据库路径、SQL、任意 URL、密钥或原始网络响应。
- TypeScript 仍是队列与 FSRS 唯一计算实现；Android 不新增 Kotlin/Rust 调度副本。
- 远程服务只能通过主进程/原生 allowlist 网络端口；密钥只从 Android Keystore 读取，不进入 renderer、日志、错误或快照。

建议扩展边界：

```text
AndroidLibraryManagementClient
AndroidReaderEnhancementClient
AndroidDictionaryCenterClient
AndroidStudyManagementClient
AndroidSettingsClient
AndroidSpeechClient
AndroidDataAndStorageClient   // E 阶段只做状态/存储；portable 写入留 F0
```

### 6.3 数据版本审计

阶段 E 默认不新增正式用户数据结构。若某功能需要新增不可再生数据：

- 新增顺序 migration，保留 migration 1；增加旧版升级和失败回滚测试。
- 若 portable v1 未覆盖该数据，新增 portable 格式版本并保留 v1 导入。
- 若影响同步，新增 Sync Model 版本与跨平台向量。
- 设置值应先判断是否已经属于 formal-v1 `settings`；资源包、网络缓存和 UI 快照不混入用户数据。

## 7. 实施子阶段

### E0：产品壳、设计系统与对照账本（已完成，2026-07-13）

目标：先建立之后所有页面共同依赖的正式移动骨架，不在原型壳上继续堆功能。

交付：

1. 四项底部导航、宽屏 navigation rail、独立 tab 栈和沉浸页面隐藏规则。
2. App-level route model：书库、词典、背单词、设置及各自子路由；系统 Back 优先级固定。
3. 四个 tab 的页面快照：路由、滚动、筛选、选中项、非敏感草稿；强制结束后只恢复可持久化状态。
4. 正式颜色/字体/间距/圆角/阴影/动效/安全区令牌和浅深主题。
5. 公共 app bar、按钮、卡片、搜索、筛选、sheet、dialog、进度、空/错/离线、snackbar。
6. 全局导入/安装/翻译/语音/数据任务模型，避免每页各自覆盖错误和进度。
7. Windows/Android 功能对照账本，给本文件第 2 节每项分配 owner、阶段、状态和验收用例。
8. 固定 UI fixture 和截图基线：360×800、412×915、横屏、600/840 dp、字体 1.0/1.3/1.5、浅/深主题。

停止条件：

- 四个根页可从底部导航稳定切换，回到各页时恢复上下文。
- 阅读/答题中不显示底部导航；Back 无死路、无跨 tab 偷跳。
- E1–E5 不再新增临时全局色值、临时 modal 或第五种导航模式。
- Windows 功能账本无“未归类”项。

## 10. 已采用的产品建议

在用户进一步调整前，计划按以下默认方向实现：

- 手机四项底部导航；宽屏自适应窄 navigation rail。
- “我的生词”不做第五个一级 tab，归入“词典”，但保留阅读器和学习页直达。
- 阅读器和答题进入沉浸模式，隐藏一级导航。
- 手机详情采用全页或 bottom sheet，不强行复刻桌面双栏。
- 产品视觉继续使用暖纸张、深墨、编辑红和衬线标题；重构的是布局与组件，不更换品牌语言。
- 功能对齐以能力、状态和结果一致为准，不以像素级复制 Windows 布局为准。

如果后续要改变一级导航数量、“我的生词”的归属或阅读/答题是否隐藏底部栏，应在 E0 结束前决定；之后再改会影响全部页面栈、截图基线和返回语义。
