# 人工发布验证清单

此清单用于正式发布，不替代 PR 的自动化门禁。自动化、破坏性与格式验证使用隔离数据目录及人工生成或可公开重建的样本；唯一例外是明确列出的 Windows 当前 Alpha 原位升级，执行前必须创建便携备份。不得把真实用户数据库、真实 `.fprbackup`、ECDICT 源文件、API 密钥、证书私钥、EPUB 或构建产物提交到仓库。

## 准备

- [ ] 确认版本号、README、CHANGELOG、正式 schema/format/Sync/content ID 状态一致。
- [ ] 完成 TypeScript、Rust、Android JVM、依赖审计、跨运行时备份、协议冒烟、性能 smoke 和 `pnpm dist`。
- [ ] 扫描源码、日志、测试临时目录、安装目录与备份内容，确认没有密钥、令牌、用户路径或真实个人数据。
- [ ] 核对 Android release keystore、别名与密码恢复资料已有仓库外备份且 ACL 仅允许当前 Windows 用户和系统读取。
- [ ] Android 正式 application ID 使用全新数据；确认旧 Demo 目录和 `.dev` 应用保持原样。

## Windows 安装与安全边界

- [ ] 从当前正式身份 Alpha 创建便携备份并核对可读取，然后完全退出应用。
- [ ] 运行 v1.0 x64 安装包原位升级，完成首次启动、退出和重启，确认现有书库、学习数据、设置与设备身份保留。
- [ ] 核对 NSIS 卸载配置默认保留用户数据；测试卸载流程时使用隔离副本，不删除唯一用户数据。
- [ ] 核对安装包没有 Authenticode，并在 README/Release 明确 SmartScreen 提示及 SHA-256 校验方法。
- [ ] 确认生产 renderer URL 为 `fpr-app://bundle/index.html`；外部导航、弹窗、子 frame IPC、未知协议文件和路径穿越均被拒绝。
- [ ] 确认合法主 frame IPC、受控 `reader-asset` 图片和系统文件选择器正常工作。

## Android 生命周期

- [ ] release APK 与 `.dev` 并存安装；核对 `com.local.foreignpressreader`、与本次 `tauri.conf.json` 一致的版本号/递增版本码、仅 `arm64-v8a`、R8、`debuggable=false` 和稳定 release 证书。
- [ ] 正式应用首次启动保持全新空白，不读取、迁移或删除 `.dev` 的 14 本书库与会话状态。
- [ ] 在当前最低支持真机和当前 API 模拟器上完成安装、冷启动、前后台、强制结束、重启和系统字体/横屏检查。
- [ ] 在 API 35 模拟器覆盖浅/深主题、360–840 dp、横竖屏、字体 1.0/1.3/1.5、reduced-motion 和 TalkBack 冒烟。
- [ ] 验证系统 Back 在覆盖层、页面栈和根页面的顺序；根页面最终把退出交还系统。
- [ ] 验证离线阅读、查词、两阶段学习答题、取消任务及错误恢复，不依赖开发服务器。
- [ ] 联网安装 ECDICT 标准包时，任务条依次显示原始数据下载字节、词形表下载字节和索引构建阶段；安装期间可切换页面，取消后不替换旧词典，成功后原始下载文件被清理且标准 SQLite 约为 24 MiB。
- [ ] 使用合成 EPUB 完成正式包导入/阅读冒烟；随后卸载并重新安装正式包，使其最终保持空白，且 `.dev` 数据仍为原样。

## EPUB

- [ ] 导入常规小型 EPUB 和至少一个接近真实外刊规模的合法 EPUB，核对栏目、文章、图片及重复导入去重。
- [ ] 人工确认 SVG/非栅格图片得到可理解的不兼容提示；取消、CRC 错误和空间不足后不留下 staging、`.part` 或数据库记录。
- [ ] 不把人工验收 EPUB 或解析输出留在仓库。

## Windows ↔ Android 局域网同步

- [ ] 两端同步页同时前台打开；正常广播路径应在 3 秒内互相出现，手动“刷新”触发重新广播与 `/24` 扫描并在 8 秒内结束。
- [ ] 设备稳定在线 60 秒不得因单次丢包闪烁；一端离开同步页后，另一端约 15 秒转为离线但保留受信任设备；证书变化显示“身份已变化”且不得在线。
- [ ] 完成首次六位码配对、双端确认、持久信任与撤销后重新配对；Windows 防火墙、固定端口占用、AP isolation、权限拒绝和 HTTPS 不可达均显示可操作诊断。
- [ ] 执行 Windows → Android 首次真实数据发送，确认超过 8 MiB 的逻辑记录可生成预览并应用，且只发送手机缺少的 `.fprpub`；再执行反向和增量发送，核对 `IncomingWins` 语义及幂等回执。
- [ ] 在源端先后导入两本刊物并同步到另一端；两端按“导入时间”排序应一致。双方独立拥有同一刊物时，同步后应保留两端较早的首次导入时间且不重复传包。
- [ ] 在批次上传完成后和部分刊物包完成后分别断网；重新进入页面并向同一设备发送，应复用原批次且不重传已完成载荷，未完成的单个载荷允许从头重试。
- [ ] 验证拒绝、主动放弃、撤销信任、成功、过期和空间不足清理对应 staging；离开页面只清理 `.part`，不得删除仍可恢复的完整批次或刊物包。
- [ ] 使用至少 500 MiB 的合成内容包限速传输：持续有进展时允许超过 30 秒，连续 60 秒无进展应中止，取消和断连后双方无 `.part` 或不完整刊物。
- [ ] 验证接近 30 分钟总期限的取消/超时诊断；不得在测试中缩短生产常量后遗漏恢复。

## 双向 SAF 便携备份

- [ ] Windows 导出 → Android SAF 导入，以及 Android SAF 导出 → Windows 导入；核对刊物、设置、阅读位置、生词、语境、计划、卡片、事件、墓碑和 reset。
- [ ] 第二次导入同一备份保持幂等；`Z` 与等价时区偏移冲突按实际时间点和 device ID 决胜。
- [ ] 中途取消、目标替换失败、损坏 manifest/hash/count、超长记录和空间不足均保持旧备份/旧数据库完整，只清理本次新建文件。
- [ ] 解压检查备份从未包含原始 EPUB、SQLite、活动队列、同步游标、词典、缓存、日志、API 密钥或同步身份。
- [ ] 当前测试阶段的 publication package 仅接受 format v2；构造或保留的 format v1 `.fprpub` 必须被明确拒绝，不得静默降级读取。

## 收尾

- [ ] 删除所有临时备份、测试用户目录、诊断包、合成大文件、unpacked 目录和安装包副本。
- [ ] 记录设备型号/API、Windows 版本、应用版本、结果和已知限制；失败项必须有复现步骤或明确阻塞原因。
