## 1. 使用规则

- 日常开发、子阶段退出和问题复现优先使用自动测试与 API 35 x86_64 模拟器；真机不要求长期连接。
- D0/D1/D2/D3 等子阶段把无法由模拟器充分证明的项目追加到本清单，不为等待设备阻塞后续可验证工作。
- A/B/C/D/E/F 等大阶段结束时集中执行所属真机清单；清单未通过时该大阶段不得标记完成或进入下一大阶段。
- 如果新原生能力、厂商兼容性或真实性能已经影响架构选择，可单独提前验证，并把结果回填本清单。
- 真机不得读取、迁移或删除旧 Demo 数据；测试样本、ECDICT、用户数据库、密钥、日志和构建产物不得提交 Git。
