# 外刊阅读器 v1.1.0

本次更新面向 Windows 与 Android，重点改善最新期刊获取、目录翻译、阅读记录与两端使用体验。

## 主要更新

- **一键补齐最近缺刊**：在“我的书库”点击“在线刊物”，直接从 `hehonghui/awesome-english-ebooks/01_economist` 获取经济学人 EPUB。默认检查最近 8 期，可选 4/12 期；自动跳过本地已有期刊，支持下载并阅读、停止、失败重试，历史期刊可按年份和日期查找。
- **目录翻译长期缓存**：翻译栏目、文章标题与摘要，支持取消、失败续译、显示/隐藏和重新翻译；重启后可继续使用本机缓存，返回目录时恢复位置。译文字号跟随正文，两端均可保存自定义翻译模型。
- **阅读与学习记录完善**：按文章恢复阅读位置，支持书签、已读状态、全库正文搜索及保留多个译文版本。再次导入同源 EPUB 可补回遗漏内容，并保留阅读和学习记录。
- **两端界面统一**：文章搜索与阅读记录入口缩为工具栏小按钮；语音服务图标、同步状态标签与同步详情适配深浅主题。
- **同步、恢复与朗读改进**：同步差异显示更清楚，修复同步后的状态刷新与删除记录问题；支持启动失败后的快照恢复；Android 朗读增加后台、锁屏及通知控制。
- 更新 EPUB 解析、内容清理、词典导入和网络栈的安全修复依赖。

## 下载与升级

- Windows 10/11 x64：`ForeignPressReader-1.1.0-Setup.exe`
- Android ARM64：`ForeignPressReader-1.1.0-android-arm64.apk`
- 文件校验：`SHA256SUMS.txt`

可覆盖安装正式 v1.0.0，正式应用身份和数据目录不变。升级前建议在设置中导出便携备份。Android 使用与 v1.0.0 相同的正式签名，版本码为 `1100000`；不读取或修改旧 Demo / `.dev` 数据。

**需要跨设备同步时，请将 Windows 与 Android 都升级到 v1.1.0。** 本版采用数据库 migration 4、便携备份 format v4 和 Sync Model v4，支持恢复旧版正式备份；旧版应用不能读取新格式备份，也不能与新版直接局域网同步。升级后的数据不支持直接降级到旧版应用。

Windows 安装包仍未使用 Authenticode，可能出现 SmartScreen 提示；请从本仓库 Release 下载并核对 SHA-256。

## 内容与隐私

EPUB 兼容范围仍为 [hehonghui/awesome-english-ebooks](https://github.com/hehonghui/awesome-english-ebooks) 中的《The Economist》。项目与该仓库及《The Economist》无隶属关系，安装包不捆绑刊物或 ECDICT 数据。

在线目录按需从 GitHub 获取，仅在点击下载时获取 EPUB；不上传本机书库，临时 EPUB 导入后清除。无账号、遥测、云端同步或后台自动上传。API 密钥不进入备份和同步。
