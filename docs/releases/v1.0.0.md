# ForeignPressReader v1.0.0

这是外刊阅读器的首个正式稳定版本，面向作者自己的 Windows 与 Android 日常阅读、查词和长期英语学习流程。

> 本项目是作者为个人使用开发和维护的本地优先外刊阅读与英语学习软件。v1.0.0 的 EPUB 导入仅保证兼容并完成验收 [hehonghui/awesome-english-ebooks](https://github.com/hehonghui/awesome-english-ebooks) 中提供的《The Economist》EPUB；其他来源或版式暂不保证可用。本项目与该仓库及《The Economist》不存在隶属关系，不捆绑、镜像或再分发任何刊物内容；MIT 许可仅覆盖本项目自身代码和图形资产。

## 下载

- Windows 10/11 x64：`ForeignPressReader-1.0.0-Setup.exe`
- Android ARM64：`ForeignPressReader-1.0.0-android-arm64.apk`
- 完整性校验：`SHA256SUMS.txt`

Windows 安装包暂未使用 Authenticode 证书，首次运行可能出现 Microsoft Defender SmartScreen 提示；请只从本 Release 下载并核对 SHA-256。

Android APK 使用项目专用的长期稳定 release key 签名，正式 application ID 为 `com.local.foreignpressreader`，`versionCode` 为 `1000006`，且不含 debug 能力。它与永久调试身份 `com.local.foreignpressreader.dev` 并存，绝不读取、迁移或删除调试应用数据。

## 安装与升级

- Windows：如果正在使用本项目的 v1.0 Alpha，请先在设置中创建便携备份，完全退出应用，再运行安装包原位升级；正式身份和数据目录不变，卸载程序默认保留用户数据。更早的 Demo 数据不会被读取、迁移或删除。
- Android：正式包是独立的全新应用，首次安装应为空白书库；它不会覆盖 `.dev` 包。后续正式版升级必须继续使用同一签名证书。
- Windows 安装包没有 Authenticode。SmartScreen 拦截时应先核对本页和 `SHA256SUMS.txt`，不要从第三方镜像下载安装。

## 主要内容

- Windows 与 Android 共用纯 TypeScript 核心、正式数据契约、学习算法和跨设备逻辑模型。
- EPUB parsed-only 导入、栏目/文章阅读、正文搜索、翻译、离线/在线词典、生词语境、FSRS-6 长期计划与每日学习。
- Windows ↔ Android 前台局域网发现、双端配对、差异预览、可恢复增量传输和显式信任管理。
- format v2 便携备份、migration 2、Sync Model v2、Wire v2 与内容 ID v2 正式基线。
- 正式红底白色“外”字图标、稳定 Android 签名、R8 release APK 和 Windows NSIS 安装包。

## 数据与隐私

- 所有核心数据默认只保存在本机；没有账号、遥测、云端同步或后台自动上传。
- 原始 EPUB 只作为一次性导入输入，不复制进应用数据目录，也不进入备份或同步。
- API 密钥只存放在 Windows DPAPI 或 Android Keystore，不进入 renderer、日志、备份或同步载荷。
- Release 不包含刊物、ECDICT 数据库、API 密钥、用户数据库或示例备份。
- ECDICT 只在用户主动安装时从固定 revision 下载并在设备本地建索引；其独立 MIT 声明见仓库 `THIRD_PARTY_NOTICES.md`。
