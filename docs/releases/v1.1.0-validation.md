# v1.1.0 发布验证

日期：2026-10-03。版本：Windows / Android `1.1.0`，Android versionCode `1100000`，正式身份 `com.local.foreignpressreader`。

## 依赖与发布范围

- 在此前已提交的在线刊物、目录翻译、阅读记录、同步和 UI 修复基础上发布；正式数据契约仍为 schema 4 / portable format v4 / Sync Model v4 / Wire v2 / content ID v2。升级说明要求两端共同升级。
- 发布审计发现并修复 JavaScript 生产依赖公告：`fast-xml-parser` 5.10.1、`sanitize-html` 2.17.7、`csv-parse` 7.0.2，以及兼容版本范围内的 `brace-expansion`、`undici`、`postcss`、`nanoid` 等传递依赖。
- Rust 网络栈更新为 `h2` 0.4.16、`rustls` 0.23.45、`rustls-webpki` 0.103.15。依赖锁文件固定实际版本，不修改正式数据向量。
- `pnpm audit:prod` 无已知漏洞。`cargo audit` 通过，保留 9 项工具允许的警告：既有未维护传递依赖、Linux `glib` unsoundness 和已撤回的 `chacha20` 0.10.1；未将这些警告写成已修复漏洞。
- 同时修正 Android Rust 插件的一处格式，使 `cargo fmt --all -- --check` 覆盖整个 workspace。

## 自动化与 Windows 打包

- `pnpm typecheck`、`pnpm lint` 通过；`pnpm test` 为 272 项通过、3 项按环境跳过；依赖更新后重新执行完整测试。

- Android 平台插件 JVM 测试 14 项通过；`pnpm test:interop` 的 TypeScript/Rust format v4 往返、幂等和回滚测试通过。
- `pnpm dist`、打包协议安全探针通过。ASAR 内版本确认为 1.1.0，未包含 EPUB、便携备份、SQLite 或 keystore 资产。Windows 安装包核对为未做 Authenticode。
